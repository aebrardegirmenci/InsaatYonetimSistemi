# 🏗 Construction Management System

A web-based construction management application developed with C# and ASP.NET Core MVC.

The system is designed to help construction companies manage their projects, workers, suppliers, materials, income and expenses in one centralized platform.

## 🚀 Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- HTML5
- CSS3
- JavaScript
- Bootstrap

## ✨ Features

- User Authentication and Login
- Project Management
- Worker Management
- Labor Management
- Supplier Management
- Material Management
- Income and Expense Tracking
- CRUD Operations

## 🗄 Database

- Microsoft SQL Server
- Entity Framework Core
- Relational Database Design

## 📂 Project Structure

| Folder / File | Description |
|---|---|
| Controllers | Application controllers |
| Models | Data models and database context |
| Views | MVC views |
| Properties | Project configuration |
| wwwroot | CSS, JavaScript and images |
| Program.cs | Application startup and configuration |

## ⚙️ Installation

1. Clone this repository.
2. Open `InsaatYonetimi.sln` in Visual Studio.
3. Configure your SQL Server connection using .NET User Secrets.
4. Make sure the `InsaatYonetimiDB` database is available.
5. Build and run the application.
